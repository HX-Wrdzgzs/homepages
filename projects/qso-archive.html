QSO 通联档案

BA4THG-QSO

用于保存和查询 QSO 记录的网站。近期记录可从上游获取，确认后的数据写入自己的长期档案。

正式站qso.mizuki.top
存储Cloudflare D1
运行Pages + Functions
01 / 数据流程

查询与归档

访客按呼号查询记录。近期数据经过校验和去重后可写入 D1，历史 ADIF、CSV 和 JSON 也可以导入。

主动查询 → 上游近期记录 → 校验 / 去重 → D1 长期档案
02 / 主要功能
按呼号查询

首页按输入的呼号返回对应记录。

长期保存

确认后的记录保存在 D1。

公开查询

访客可以查询记录，后台管理保持独立。

历史导入

支持整理已有的 ADIF、CSV 和 JSON 数据。
