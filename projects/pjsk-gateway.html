PJSK / Web

PJSK Gateway

hx-pjsk-gateway

给 PJSK 网页查询做的一层网关。网页、机器人身份确认和数据节点不在一个地方，所以中间需要一层把请求和结果接起来。

前端React / Vite
网关FastAPI
状态Redis / MySQL
01 / 做什么

网页发一个查询，后面其实要走好几步。

Gateway 会先记住这次请求，再让机器人侧确认身份，之后去数据节点拿结果。每次请求都有自己的标识，多人一起用时也不会把结果串掉。

Browser → Gateway → Bot 验证 → Data Node → Browser
02 / 主要处理
身份确认

把网页会话和机器人侧已有身份对应起来。

请求隔离

每次查询有自己的标识，避免并发串数据。

图片处理

机器人返回的本地图片转成网页能访问的资源。

公网入口

Cloudflare 负责入口，应用自己的鉴权照常保留。
