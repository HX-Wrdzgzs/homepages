Project SEKAI / Web / Bot

HX PJSK Gateway

PJSK 网页查询这边中间那一层。网页发请求，机器人侧确认身份，再去数据节点拿结果。看起来只是查一次数据，背后其实要跨好几个东西。

前端
React · Vite · TypeScript
网关
FastAPI · asyncio
状态
MySQL · Redis · Cloudflare
01 / 怎么走

网页不直接碰机器人和数据节点。

Browser
   │
   ▼
Gateway API
   │
   ▼
机器人侧验证
   │
   ▼
数据节点
   │
   ▼
结果 / 图片 / Web 展示

这样做主要是为了把身份验证、并发请求和内部节点隔开。尤其多人一起查的时候，不能把 A 的结果回给 B。

02 / 比较麻烦的地方

能查到不难，别串包更重要。

机器人侧确认身份

网页会话要和机器人里已有的用户数据对应上。

并发请求分开

每个请求都有自己的标识，返回结果时按标识找回去。

图片单独处理

机器人返回本地图片时，不能把内部路径直接丢给浏览器。

Cloudflare 在外面挡一层

入口、防护和应用自己的鉴权各管各的，不混在一起。

03 / 现在

还在继续补业务页面和异常处理。

这类东西最烦的是某一个节点偶尔慢、偶尔断，所以除了功能本身，还得把超时、重试和状态恢复补全。
