仓库 / hx-pjsk-gateway

hx-pjsk-gateway

PJSK 网页查询用的网关，连接网页、机器人身份确认和数据节点。

前端React / Vite
网关FastAPI
状态Redis / MySQL
01 / 做什么

把网页查询接到后面的服务。

网页发起请求后，网关先保存这次请求，再让机器人侧确认身份，之后去数据节点取结果。多人同时使用时，每次请求都需要单独对应。

Browser → Gateway → Bot 验证 → Data Node → Browser
02 / 主要内容
身份确认

网页会话和机器人侧已有身份对应起来。

请求隔离

每次查询使用自己的请求标识。

图片处理

把机器人侧图片转换成网页可以访问的资源。

公网入口

Cloudflare 提供入口，应用侧仍保留自己的鉴权。
