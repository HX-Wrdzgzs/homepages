PJSK / Web

PJSK Gateway

hx-pjsk-gateway

PJSK 网页查询使用的网关服务，负责连接网页、Bot 身份验证与数据节点。

前端React / Vite
网关FastAPI
状态Redis / MySQL
01 / 流程

查询链路

网关为每次请求分配标识，完成身份确认后从数据节点获取结果，再返回网页。

Browser → Gateway → Bot 验证 → Data Node → Browser
02 / 主要功能
身份确认

关联网页会话与 Bot 侧已有身份。

请求隔离

使用独立请求标识处理并发查询。

图片处理

将查询结果中的本地图片转换为网页可访问资源。

公网入口

Cloudflare 提供公网入口，应用鉴权仍由服务本身处理。
