PJSK / Web

HX PJSK Gateway

PJSK 网页查询用的中间层。浏览器、机器人身份确认和数据节点不在一个地方，所以需要有人把这几边接起来。

前端React / Vite
网关FastAPI
状态Redis / MySQL
01 / 这是干什么的

网页发一个查询，后面其实要绕好几步。

用户在网页上发请求，Gateway 先记住这次请求，再让机器人侧确认身份，之后去数据节点拿结果。并发时最重要的是别把 A 的结果发给 B。

Browser → Gateway → Bot 验证 → Data Node → Browser
02 / 现在有些什么

现在主要盯身份和并发这两件事。

能查到只是第一步，更麻烦的是多人一起用时别串数据、内部路径别直接漏给网页。

身份确认

网页会话和机器人侧已有身份对应起来。

请求隔离

每次查询有自己的标识，避免并发结果串掉。

图片处理

机器人返回的本地图片要先转成网页能访问的资源。

公网入口

Cloudflare 负责入口，应用自己的鉴权还是要保留。
