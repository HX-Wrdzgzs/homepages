硬件 / 系统 / 本地监控

Retro Monitor

把 Windows 主机遥测、Home Assistant 实体管理和 ESP32-S3 桌面终端组合成一条完整的本地数据链路。它不是单独一个“小屏幕”，而是三个可以独立部署、在局域网里协作的组件。

定位
本地硬件监控与多媒体显示系统
主要技术
C# · Home Assistant · ESPHome
设备侧
ESP32-S3 · OLED · Camera · Audio
01 / 它是什么

从电脑传感器，一直走到桌面终端。

Windows Agent 负责采集 CPU、GPU、内存、磁盘、风扇、网络和功耗等状态，并通过 HTTP 提供缓存后的遥测快照。Home Assistant 自定义集成轮询 Agent、验证数据并创建实体；ESP32-S3 终端再从 Home Assistant 读取稳定的聚合实体用于显示和交互。

Windows PC
  │  C# / ASP.NET Core / .NET 8
  │  GET /health · GET /telemetry
  ▼
Home Assistant
  │  Python 自定义集成 / local polling
  │  desktop_current_* 聚合实体
  ▼
ESP32-S3 桌面终端
  ├─ 128×64 OLED
  ├─ OV2640 摄像头
  ├─ MAX98357 扬声器
  ├─ INMP441 麦克风
  └─ DHT11 温湿度
02 / 主要能力

三个部分，各自负责清晰的边界。

Windows Agent

后台周期采样硬件状态，提供健康检查与遥测接口，也支持作为 Windows Service 部署。

Home Assistant

通过 Config Flow 添加 Agent，创建 CPU/GPU/内存/磁盘/网络/功耗等实体，并支持多主机。

桌面终端

显示 Windows、环境和设备状态，同时提供摄像头、音频、语音与传感能力。

稳定数据入口

使用 desktop_current_* 聚合实体，让设备端不必绑死具体电脑的动态实体 ID。

设计上的一个原则

缺失传感器使用 null，不制造“看起来正常”的假数据。三个组件可以分别升级或替换，避免把采集、家庭自动化和终端固件绑成一个不可维护的大块。

03 / 技术与边界

更像一条小型系统链路，而不是单个硬件 Demo。

  • Windows 10 / 11 与兼容 Windows Server 环境。
  • Agent 使用 C#、ASP.NET Core、.NET 8 和 LibreHardwareMonitor。
  • Home Assistant 侧使用 Python 自定义集成与聚合 package。
  • 终端使用 ESPHome / ESP-IDF / C++，参考设备为 ESP32-S3。
  • 当前参考设备包含 OLED、摄像头、I2S 麦克风和扬声器、DHT11。
