Retro Monitor

最开始只是想把电脑状态放到桌面小屏上，后来顺手把 Windows、Home Assistant 和 ESP32-S3 都接进来了。

电脑侧C# / .NET
中间层Home Assistant
终端ESP32-S3
01 / 这是干什么的

电脑采数据，Home Assistant 收着，小屏负责看。

Windows 侧采集 CPU、GPU、内存、磁盘和网络这些数据，Home Assistant 把它们整理成实体，桌面终端再从 HA 里读。三个部分可以分开升级，不用绑成一个大程序。

Windows Agent → Home Assistant → ESP32-S3 桌面终端
02 / 现在有些什么

它现在更像一条自己家里在用的小链路。

每个部分都只做自己那一段，坏了或者想换掉时不用整套推倒重来。

Windows Agent

周期采集硬件状态并提供本地接口。

Home Assistant

把数据做成实体，也方便多台机器一起管理。

桌面终端

OLED、摄像头、音频和环境传感都可以接。

不造假数据

拿不到的传感器就留空，不硬凑一个“正常值”。
