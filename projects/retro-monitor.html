Retro Monitor

一开始只是想把电脑的温度、负载这些数据显示出来，后来顺手把 Home Assistant 和 ESP32-S3 也接进来了。现在它分成 Windows 采集、HA 实体和桌面小终端三块。

电脑端
C# · ASP.NET Core · .NET 8
中间层
Home Assistant
终端
ESP32-S3 · ESPHome
01 / 怎么接的

电脑采集，HA 整理，小屏幕负责显示。

Windows Agent 定时读取 CPU、GPU、内存、磁盘、风扇、网络和功耗这些数据，对外给一个简单的 HTTP 接口。Home Assistant 再把它们变成实体，ESP32-S3 从 HA 里取稳定的数据来显示。

Windows PC
  │  /health · /telemetry
  ▼
Home Assistant
  │  desktop_current_* 实体
  ▼
ESP32-S3
  ├─ OLED
  ├─ 摄像头
  ├─ 麦克风 / 扬声器
  └─ 温湿度
02 / 现在有啥

不只是一个显示温度的小屏幕。

Windows Agent

后台采集硬件状态，也可以装成 Windows Service。

Home Assistant

统一管理实体，多台电脑也能接。

ESP32-S3 终端

除了显示状态，还接了摄像头、音频和环境传感器。

数据缺了就缺了

读不到的传感器直接给 null，不编一个看起来正常的假数值。

03 / 备注

三块东西可以各自换，不用绑死。

采集、Home Assistant 和终端是分开的，所以以后换显示设备、换电脑，或者只想用其中一部分都比较方便。
