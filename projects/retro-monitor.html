Retro Monitor

retro-monitor

把电脑硬件状态送到桌面小屏上的一套监控方案。Windows 端采集数据，Home Assistant 做中转，最后交给 ESP32-S3 显示。

采集C# / Windows
中转Home Assistant
终端ESP32-S3
01 / 做什么

把电脑状态搬到桌面上。

Windows 端负责拿温度、负载等硬件数据，Home Assistant 接住以后再把需要的内容送到 ESP32-S3。终端只负责显示，不用自己再去解析电脑上的各种数据源。

Windows → Home Assistant → ESP32-S3
02 / 几部分
Windows 采集

从电脑侧拿到硬件状态并整理成固定格式。

Home Assistant

统一接收和转发数据，也方便以后继续接别的设备。

ESP32-S3

桌面端只处理显示和必要的交互。

本地链路

整个方案主要给自己的桌面环境使用。
