仓库 / retro-monitor

retro-monitor

把 Windows 硬件状态接到 Home Assistant，再送到 ESP32-S3 桌面终端。

WindowsC#
中间层Home Assistant
终端ESP32-S3
01 / 做什么

把电脑状态送到桌面小屏。

Windows 端负责采集硬件状态，数据进入 Home Assistant 后再提供给 ESP32-S3 终端显示。

Windows → Home Assistant → ESP32-S3
02 / 主要内容
Windows 采集

读取温度、负载等硬件状态。

Home Assistant

把数据接进现有自动化环境。

ESP32-S3

在桌面终端上显示状态。

本地链路

主要围绕自己的设备和网络使用。
