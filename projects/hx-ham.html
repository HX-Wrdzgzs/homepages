无线电 / Windows

业余无线电点名助手

ham-checkin-assistant

用于中继点名现场的 Windows 本地录入工具。记录呼号、地点、设备等信息，并按场次保存，需要时同步到 Excel。

主要数据SQLite
协作输出Excel
平台Windows
01 / 功能

记录点名现场信息

输入内容会解析为结构化字段。无法确认的内容保留原始输入，之后可以人工检查。

现场输入 → 解析 / 历史建议 → SQLite → Excel
02 / 主要功能
本地存储

现场记录写入 SQLite，Excel 用于协作和导出。

历史建议

根据已有记录提供 QTH、设备和功率提示。

离线使用

主要录入流程不依赖网络。

场次管理

不同点名场次分开保存，并可检查同步状态。
