无线电 / Windows

业余无线电点名助手

ham-checkin-assistant

给中继点名现场用的 Windows 本地录入工具。现场先快速把呼号和相关信息记下来，后面再整理，不需要一边点名一边慢慢填表。

主要数据SQLite
协作输出Excel
平台Windows
01 / 做什么

先把现场记录稳稳记下来。

呼号、地点、设备、天线和功率可以按现场习惯输入，程序再把它们拆成结构化字段。识别不准的内容会留下来，方便之后人工确认。

现场输入 → 解析 / 历史建议 → SQLite → Excel
02 / 现在有的功能
SQLite 优先

记录先落本地主库，Excel 同步失败之后还能补。

历史建议

以前用过的 QTH、设备和功率可以拿来做提示。

离线可用

核心录入流程不依赖网络。

场次管理

每次点名单独记录，结束前可以检查同步情况。
