业余无线电 / Windows / 本地工具

HX-HAM

面向业余无线电中继点名和主控现场的 Windows 本地录入助手。核心目标不是“让 AI 代替主控”，而是把现场快速输入稳定地整理成结构化记录，并降低重复录入和事后整理成本。

核心数据
SQLite 本地主库
协作输出
Excel 实时联动与补同步
关键能力
呼号解析 · 历史画像 · 模糊匹配
01 / 输入流程

允许现场输入很乱，但落库必须规整。

主控可以把呼号、QTH、设备、天线和功率按现场习惯快速输入，不要求固定字段顺序。程序会结合规则、拼音和地区缩写、常见设备型号、历史画像与模糊匹配，把内容拆成结构化字段。

现场输入
ba4thg njqx k5 y 5
        │
        ▼
规则解析 / 缩写词典 / 历史画像 / 模糊匹配
        │
        ▼
BA4THG | 南京栖霞 | 泉盛 UV-K5 | 原装天线 | 5W
        │
        ├─ SQLite 优先落库
        └─ Excel 后台同步

无法可靠判断的 token 不会静默丢掉，而是保留到“未识别”字段，之后可以人工修正或补充词典。

02 / 为什么本地优先

点名现场不应该依赖 Token、LLM 或网络是否正常。

核心流程离线

点名、历史记录、SQLite 和 Excel 录入不依赖 AI、LLM、Token 或语音识别。

SQLite 优先

记录先写本地主库，再处理 Excel，同步失败可以保留状态并补同步。

历史建议可控

最近一次和最常用的 QTH、设备、天线、功率只作为建议，需要人工接受。

场次隔离

每次点名作为独立场次管理，支持只读结束、异常恢复、软删除和一致性检查。

03 / 额外能力

联网能力是增强项，不是单点故障。

  • 可以导入已有 Excel 历史记录并生成呼号画像。
  • 365dt 历史同步属于可选联网能力，网络异常不影响本地点名。
  • NRL Nanny 只读监听可以提供候选呼号，但不会自动写库或自动提交。
  • Windows 单实例保护用于避免多个实例同时写数据库。
  • 结束场次前可以执行 SQLite / Excel 一致性检查和补同步。
