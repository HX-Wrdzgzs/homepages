ham-checkin-assistant

这个仓库里的程序名是 HX-HAM。它是给中继点名现场用的 Windows 本地录入工具。

程序名HX-HAM
主要数据SQLite
协作输出Excel
01 / 做什么

现场先快点记，后面再整理。

点名的时候很难按表格一格一格填，所以允许先按现场习惯快速输入，再把呼号、地点、设备、天线和功率这些字段拆出来。识别不准的内容会留下来，方便之后人工确认。

现场输入 → 解析 / 历史建议 → SQLite → Excel
02 / 现在有的功能
SQLite 优先

记录先落进本地主库，Excel 同步失败之后还能补。

历史建议

以前用过的 QTH、设备和功率可以拿来做建议。

离线可用

核心点名流程不依赖 LLM、Token 或网络。

场次管理

每次点名单独记录，结束前可以检查同步情况。
