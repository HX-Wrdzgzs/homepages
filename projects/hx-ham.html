业余无线电 / Windows

HX-HAM

给中继点名现场用的本地录入工具。重点不是做得多花，而是输入快、记录别丢、事后少整理。

主要数据SQLite
协作输出Excel
使用场景中继点名 / 主控
01 / 这是干什么的

把现场那一串输入收拾好。

点名的时候很难按表格一格一格填，所以允许先按现场习惯快速输入，再把呼号、地点、设备、天线和功率这些字段拆出来。识别不准的内容宁愿留下来，也不直接装作自己看懂了。

现场输入 → 解析 / 历史建议 → SQLite → Excel
02 / 现在有些什么

现在还是围绕“现场别添堵”继续补。

核心流程尽量本地完成，网络功能放在旁边，不让它们变成点名现场的单点故障。

SQLite 优先

先把记录落进本地主库，Excel 同步失败之后还能补。

历史建议

以前用过的 QTH、设备和功率可以拿来做建议，但不会直接替你决定。

离线也能用

核心点名流程不靠 LLM、Token 或网络。

场次管理

每次点名分开记录，结束前可以检查同步情况。
