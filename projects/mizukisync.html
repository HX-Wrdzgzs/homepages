Android / 舞萌 DX

MizukiSync

给舞萌 DX 用的 Android 第三方客户端。主要就是查玩家信息、成绩、曲库和同步数据，不想每次都只在网页或者 Bot 里看。

客户端
Kotlin · Android
后端
FastAPI
数据
成绩 · 曲库 · 玩家状态
01 / 怎么分

客户端管界面，后端管数据。

Android 这边负责页面、本地缓存和交互；FastAPI 后端负责第三方接口、曲库清洗和数据格式转换。需要保密的 API Key 也留在服务端，不塞进 APK。

Android 客户端
  ├─ 玩家信息
  ├─ 成绩 / 最近游玩
  ├─ 曲库和筛选
  └─ 本地缓存
        │
        ▼
FastAPI
  ├─ 第三方数据
  ├─ 曲库清洗
  └─ 配置与密钥
02 / 现在能看啥

重点还是把常看的东西放到手机里。

玩家名片

Rating、段位、阶级、底板、头像和称号这些。

曲库筛选

按定数、版本和分类找歌，少翻几层页面。

成绩同步

同步玩家状态，也能看最近游玩和单曲结果。

本地缓存

能不重复拉的数据就别每次重新请求。

03 / 现在

目前还在继续改，尤其是 UI。

公开仓库主要放项目结构和现有实现，不保证拿下来就能直接部署。第三方接口也可能变化，所以这东西本身就是边用边维护。
