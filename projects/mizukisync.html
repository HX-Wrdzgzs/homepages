Android / 舞萌 DX / 数据同步

MizukiSync

面向舞萌 DX 玩家的 Android 第三方客户端，通过对接 LXNS 相关数据能力提供成绩查询、曲库检索、筛选与同步体验。客户端负责交互和缓存，后端负责数据清洗、接口转发与敏感配置边界。

客户端
Kotlin · Android
后端
Python · FastAPI
数据方向
成绩 · 曲库 · 玩家状态
01 / 架构

前后端分开，是为了体验，也是为了安全边界。

Android 客户端承担界面展示、本地缓存和用户交互；后端统一处理第三方 API 调用、数据清洗、版本去重和格式转换。真实的开发者 API Key 与私密配置保留在服务端，不进入客户端包。

Android 客户端
  ├─ 玩家名片 / 最近游玩
  ├─ 曲库检索与筛选
  ├─ 本地缓存
  └─ 用户交互
        │
        ▼
FastAPI 后端
  ├─ LXNS 数据转发
  ├─ 曲库清洗 / 版本去重
  ├─ 数据格式转换
  └─ 私密凭证托管
02 / 主要能力

把“查成绩”和“找曲子”做成移动端产品体验。

玩家名片

展示 Rating、段位、阶级、底板、头像、称号等信息。

曲库筛选

支持按定数范围、游戏版本和乐曲分类筛选，后端负责定时同步与清洗。

成绩同步

同步玩家最新状态，并展示最近游玩、单曲达成率与评级等结果。

客户端缓存

减少重复请求成本，让移动端页面不必每次都等待同一批数据。

03 / 当前边界

公开可见，不等于公开部署模板。

项目目前主要由个人与开发组内部维护，README 记录的是项目定位、结构和维护注意事项，并不承诺外部环境可以直接部署。仓库当前也没有选择开源许可证。

  • 第三方 API 格式和可用性可能随上游变化。
  • 敏感配置不得进入客户端包或代码仓库。
  • 游戏资产版权归原开发商和相关权利方所有。
