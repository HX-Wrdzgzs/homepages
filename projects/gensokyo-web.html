02 / 写文档时注意啥

宁可少写，也别把旧行为写成现在还有效。

源码和 Release 优先

版本差异先看主仓库，文档跟着实际行为走。

分清谁的能力

QQ 官方、OneBot 标准和项目扩展不要混成一件事。

不乱写性能结论

没测过的东西不写成长期保证。

示例不放真密钥

Token 和登录凭据一律用占位符。

03 / 维护

改导航和页面之后，至少先构建一遍。

这个站不是随便丢 Markdown。内部链接、Vue 组件和主题样式都要一起过构建，免得线上某个入口突然断掉。
